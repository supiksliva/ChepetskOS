## ⚡ Главные фичи системы

### 1. Пакетный менеджер `bayan` (Баян)
Ставит пакеты напрямую в вену системы. Зависимости варятся на ложке.
```bash
bayan vmazat nginx      # Установить пакет внутривенно
bayan zavyazat nginx    # Удалить пакет и соскочить с зависимости
bayan lomka             # Накатить все обновления системы (кумары)
bayan shmon python      # Пошустрить в поисках стаффа
```

### 2. Диспетчер служб моногорода `monoctl`
Заменяет скучный буржуйский `systemctl`. Управляет агрегатами, службами и цехами комбината:
```bash
monoctl start docker        # Запустить цех в дневную смену (или 'monoctl nalyat')
monoctl stop docker         # Экстренно остановить конвейер (или 'monoctl otrubit')
monoctl status docker       # Снять показания аммиачных датчиков (или 'monoctl belochka')
monoctl restart docker      # Перезапустить котёл на вторую смену (или 'monoctl do-dna')
monoctl list                # Сводка активных цехов и агрегатов на районе
```

### 3. Системный информер `chepfetch`
Выводит актуальный уровень аммиака из трубы комбината, замер запоя и статус заложенных вещей в ломбарде на пр. Мира.

### 4. Монитор ресурсов `lomkatop`
Вместо `htop` показывает тремор рук процессора, процент пропитой памяти и список процессов, которые шарятся по району в поисках дозы.

### 5. Охотник на буржуев `detect-trezvost`
Рейд по карманам пользователя: выявляет трезвый и хипстерский софт (VS Code, Spotify, Slack, Telegram) и предлагает отжать его.
```bash
detect-trezvost            # Сканировать карманы
detect-trezvost --otzhat   # Принудительно снести хипстерский софт
```

### 6. Убийца памяти `krokodil-killer`
Фоновый демон. Когда свободной памяти остаётся меньше 10%, не церемонится — отпиливает самый жирный процесс ржавой ножовкой и сбрасывает остатки в реку Чепцу.

### 7. Крокодиловый Антивирус `krokodil-av`
Первый в мире антивирус, который лечит систему паяльником и серной кислотой. Ищет штаммы трезвости (ESLint, Prettier, ClamAV, SELinux) и зачищает следы милицейских жучков:
```bash
krokodil-av scan        # Сканировать систему на ментовские жучки и буржуазный софт
krokodil-av prizhech    # Выжечь заразу паяльником и залить техническим спиртом
krokodil-av obnovit     # Обновить базу штаммов через деда Мазая с химзавода
krokodil-av karantin    # Заглянуть в подвал на Боёво, куда сброшены улики
```

## 🗂 Перебитая файловая система

Вместо буржуйского стандарта FHS вводится **Чепецкий FHS**:
- `/hata` → твоя домашняя папка (`/home`)
- `/pomoyka` → временные файлы (`/tmp`)
- `/ponyatiya` → системные конфиги (`/etc`)
- `/dev/reka-cheptsa` → чёрная дыра для улик и отходов (`/dev/null`)

---

## 🛠 Шелл-понятия (`gopsh`)

После установки терминал переходит на аутентичный сленг:
- `shmon` → `ls -la`
- `poyti <путь>` → `cd`
- `vskryt <файл>` → `cat`
- `v_cheptsu <файл>` → `rm -rf`
- `krysha` → `sudo`
- `pereдоз <pid>` → `kill -9`
- `s_boduna` → `reboot`
- `v_otkluchku` → `shutdown -h now`
- `zanyat_sotku` → `free -h`

## 🚀 Установка

Клонируй репозиторий и накати понятия под root:

```bash
git clone https://github.com/supiksliva/ChepetskOS.git
cd ChepetskOS
sudo ./install.sh
```

Чтобы принудительно закодироваться и вернуть всё назад:
```bash
sudo ./uninstall.sh
```
