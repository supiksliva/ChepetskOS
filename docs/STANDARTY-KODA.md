# ГОСТ КЧХК-1998: Стандарты разработки кода по понятиям

Настоящий стандарт обязателен для всех соучастников разработки дистрибутива **ChepetskOS**. Нарушение карается выездом на очистные сооружения в багажнике.

---

### Основные правила:

1. **Никакого ООП**: Классы, интерфейсы и полиморфизм придумали пижоны из Москвы. В Чепецке код льётся сплошной струёй, как отходы аммиака в реку.
2. **Запрет `try-catch`**: Ошибки не обрабатываются. Если код падает, оператор должен молча терпеть. Вся область терпит, и процесс потерпит.
3. **Комментарии**: В коде запрещены. Единственный допустимый комментарий: `# Петрович, не трогай тут ничего, убьет`.
4. **Имена переменных**:
   - `a`, `b`, `c` — разрешено;
   - `bayan`, `shpritz`, `funfyrik`, `menty` — приветствуется;
   - `UserManagerFactoryDelegate` — бан по IP навсегда.
5. **Тестирование**: Юнит-тесты — признак слабости духа. Единственный валидный тест — запуск скрипта в продакшене под дождём на остановке у завода.
6. **Дебаг**: Только `echo "бля"` и `echo "сюда дошло"`. Использование gdb расценивается как сотрудничество с милицией.
7. **Форматирование кода**: Отступы ставятся пробелами случайной длины в зависимости от уровня тремора пальцев.
8. **Системные зависимости**: Чем меньше библиотек, тем меньше шансов, что их украдут цыгане на рынке.
